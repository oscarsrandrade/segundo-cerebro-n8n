# 🧠 Meu Segundo Cérebro: Especialista em Automação com n8n

Este repositório documenta a criação de um "segundo cérebro" utilizando o Gemini Notebook (antigo NotebookLM), desenvolvido como desafio prático.

## 🎯 Objetivo
Atuar como um consultor técnico especialista para estruturar workflows no n8n, focando em automatizar o controle de operações e integrar planilhas, APIs e sistemas de gestão de forma eficiente e sem trabalho manual.

## 📚 Fontes Utilizadas
As fontes foram selecionadas baseadas em três critérios: conteúdo atualizado (recente), foco prático (mão na massa) e confiabilidade da origem.

1. **[Documentação Oficial do n8n - Google Sheets]** - Base teórica e manual técnico oficial.
2. **[Vídeo: N8N na Prática - Como Criar sua Conta...]** - Mostra a configuração do ambiente Cloud e primeiros passos.
3. **[Vídeo: Automação com Tiny API e Google Sheets]** - Foco logístico e operacional, mostrando como puxar dados via API e salvar em planilhas na prática.

## 🤖 Diretriz de Comportamento (Prompt)
"Comporte-se como um engenheiro de automação sênior especialista em n8n. Seu objetivo é me ajudar a estruturar workflows integrando planilhas e APIs para controle de operações. Responda sempre de forma técnica, passo a passo, baseando-se estritamente nos vídeos e documentações fornecidos. Se a solução envolver um nó (node) específico, explique como configurá-lo."

## 💬 Exemplo de Interação
**Pergunta:** "Estou montando uma automação com o nó (node) do Google Sheets. Explique passo a passo como eu configuro esse nó para adicionar novas linhas (append/update row) em uma planilha existente."

**Resposta da IA (Resumo):** O assistente explicou perfeitamente os passos para selecionar a operação "Append Row", mapear a planilha, escolher a aba correta e cruzar os IDs/colunas (como SKU, Descrição e Preço), citando o vídeo da integração com a Tiny API.
